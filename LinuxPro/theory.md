# Linux: уверенный пользователь

## Структура папок в Linux

Linux использует единую иерархию файловой системы, которая начинается с корня `/`.

- `/etc` - системные конфигурационные файлы. Например настройки сервисов, сети, пользователей.
- `/var` - изменяемые данные: логи, кеши, очереди, базы некоторых сервисов.
- `/usr` - пользовательские системные программы, библиотеки и документация. Часто содержит `/usr/bin`, `/usr/lib`, `/usr/share`.
- `/lib`, `/lib64` - системные библиотеки, нужные для запуска базовых программ и загрузки системы.
- `/opt` - стороннее программное обеспечение, установленное отдельно от основной системы.
- `/dev` - файлы устройств: диски, терминалы, псевдоустройства.
- `/boot` - файлы загрузчика, ядро Linux.
- `/run` - временные runtime-файлы после загрузки системы: PID-файлы, сокеты, lock-файлы.

## Где лежат бинарники

Исполняемые файлы обычно находятся в:

```bash
/bin
/sbin
/usr/bin
/usr/sbin
/usr/local/bin
/opt/<program>/
```

Примеры:

```bash
which ls
which bash
which python3
```

## PATH

`PATH` - переменная окружения со списком директорий, где shell ищет исполняемые файлы.

Посмотреть:

```bash
echo "$PATH"
```

Временно добавить директорию:

```bash
export PATH="$PATH:/my/custom/bin"
```

Чтобы добавить путь постоянно для пользователя, запись обычно добавляют в `~/.bashrc` или `~/.bash_profile`.

## .bashrc vs .bash_profile

`~/.bashrc` выполняется для интерактивного non-login shell. Обычно это новый терминал в графической среде. Можно написать что угодно, но обычно настройки интерактивной работы в терминале, алиасы

`~/.bash_profile` выполняется для login shell. Например, при входе по SSH.

Часто в `~/.bash_profile` подключают `.bashrc`:

```bash
if [ -f ~/.bashrc ]; then
  source ~/.bashrc
fi
```

## Пакетные менеджеры: apt, dpkg, snap

`apt` - высокоуровневый пакетный менеджер Debian/Ubuntu. Он устанавливает пакеты из репозиториев, разрешает зависимости и обновляет систему.

```bash
sudo apt update
sudo apt install nginx
sudo apt remove nginx
```

`dpkg` - низкоуровневая утилита для работы с `.deb` пакетами. Она устанавливает конкретный файл пакета, но сама не скачивает зависимости из репозиториев.

```bash
sudo dpkg -i package.deb
sudo dpkg -l
sudo dpkg -r package-name
```

Если после установки через `dpkg` не хватает зависимостей:

```bash
sudo apt -f install
```

`apt` обычно используют для повседневной установки и обновления ПО. `dpkg` нужен, когда есть конкретный `.deb` файл или нужно напрямую посмотреть/управлять deb-пакетами.

`snap` - отдельная система пакетов от Canonical. Snap-пакеты обычно изолированы, могут содержать свои зависимости и обновляются отдельно.

|APT|Snap|
|---|---|
|ставит классические системные пакеты из официальных репозиториев дистрибутива, разделяя общие библиотеки между программами.|создает изолированные контейнеры со всеми нужными зависимостями прямо внутри одного пакета|
|программы имеют полный доступ к системе в рамках прав пользователя|работают изолированно от остальной системы для безопасности|
|занимает мало места, программы запускаются быстро|занимают больше места на диске|
|обновляется вручную или вместе со всей системой.|обновляется сам в фоне автоматически|


```bash
snap list
sudo snap install code
sudo snap remove code
```

## Репозитории Ubuntu

Основные файлы репозиториев:

```bash
/etc/apt/sources.list
/etc/apt/sources.list.d/*.list
```

В новых версиях Ubuntu также могут использоваться `.sources` файлы:

```bash
/etc/apt/sources.list.d/*.sources
```

После изменения репозиториев нужно обновить индекс пакетов:

```bash
sudo apt update
```

Подписи сторонних репозиториев обычно хранятся через keyring-файлы, например:

```bash
/usr/share/keyrings/
```

Посмотреть подписи

```bash
apt-key list
gpg --show-keys /etc/apt/keyrings/*.gpg
```

Добавление нового ключа:

```bash
curl -fsSL https://example.com/repo.gpg | \
sudo gpg --dearmor -o /etc/apt/keyrings/example.gpg
```
И затем в записи репозитория:

```bash
deb [signed-by=/etc/apt/keyrings/example.gpg] https://example.com/debian stable main
```

## stdin, stdout, stderr и перенаправления

- `stdin` - стандартный ввод, файловый дескриптор `0`.
- `stdout` - стандартный вывод, файловый дескриптор `1`.
- `stderr` - стандартный вывод ошибок, файловый дескриптор `2`.

Примеры:

```bash
command > out.txt        # stdout в файл
command >> out.txt       # stdout дописать в файл
command 2> error.txt     # stderr в файл
command > all.txt 2>&1   # stdout и stderr в один файл
command < input.txt      # stdin из файла
```

## Операторы управления

```bash
cmd1 ; cmd2
```

Выполнить команды последовательно независимо от результата.

```bash
cmd1 | cmd2
```

Передать stdout первой команды во stdin второй.

```bash
cmd &
```

Запустить команду в фоне.

```bash
echo $name
```

Вывести значение переменной.

```bash
echo $?
```

Показать код завершения последней команды. `0` означает успех, не `0` - ошибку.

```bash
echo $0
```

Показать имя скрипта.

```bash
echo $1
```

Показать первый аргумент.

```bash
echo $#
```

Показать количество аргументов.

```bash
echo $*
```

Показать все аргументы (если в кавычках, то в одну строку).

```bash
echo $@
```

Показать все аргументы (как отдельные аргументы).

```bash
ls file?
```

? заменяется на любой символ.

```bash
cmd1 && cmd2
```

Выполнить `cmd2`, только если `cmd1` завершилась успешно.

```bash
cmd1 || cmd2
```

Выполнить `cmd2`, только если `cmd1` завершилась с ошибкой.

```bash
\
```

Перенос длинной команды на следующую строку.

Пример:

```bash
sudo apt update && \
sudo apt upgrade -y
```

## Как обновить Ubuntu

Обновить список пакетов:

```bash
sudo apt update
```

Обновить установленные пакеты:

```bash
sudo apt upgrade
```

Полное обновление с возможной заменой или удалением зависимостей:

```bash
sudo apt full-upgrade
```

Удалить ненужные зависимости:

```bash
sudo apt autoremove
```

Обновить релиз Ubuntu:

```bash
sudo do-release-upgrade
```

Топ 3 города

```bash
awk '{print $3}' "users.txt" | sort | uniq -c | sort -nr | head -3
```

1. awk '{print \$3}' "users.txt"
   Читает файл и печатает только третий столбец каждой строки.
   Для примера users.txt результат будет:
   Moscow
   Saint-P
   Tver
   Milan
   Moscow

2. sort
   Сортирует города по алфавиту.
   Это нужно перед uniq, потому что uniq считает только соседние одинаковые строки.

3. uniq -c
   Объединяет одинаковые соседние строки и добавляет количество повторений.
   Например:
   2 Moscow
   1 Milan

4. sort -nr
   Сортирует результат по числу повторений.
   -n означает числовую сортировку.
   -r означает обратный порядок, то есть от большего к меньшему.

5. head -3
   Оставляет только первые 3 строки, то есть 3 самых популярных города.
